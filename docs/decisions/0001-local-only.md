# 0001 纯本地：不登录、不上传，联网只有三件事

日期：2026-11-03　状态：有效

## 背景

AI 编程工具的日志里有提示词、代码、项目路径和账号信息。统计用量只需要其中很少几个字段，但用户要先确信这些内容不会离开电脑，才愿意让一个程序去读它们。

## 决定

- 只在本机读取日志，只提取用量元数据（四类 token、模型、时间、会话、项目路径），提示词、回复、代码和凭据不进账本。
- 没有账号、上传、遥测和第三方分析。
- 联网只有三件事：AI 热点刷新、用户点击时更新汇率、每天最多一次检查新版本。三者都可以关掉或不触发，请求都不带账号、凭据或用量数据。
- 不改其他工具的任何文件，不给它们装钩子或插件。

## 放弃的做法

旧版功能规格里不做的清单见 [features.md](../archive/features.md)。

- 云端同步、多设备合并、排行榜和分享页：都需要上传数据。
- 给客户端装钩子实时上报：要改别人的配置，而且只能统计装钩子以后的用量。

## 后果

- 想换电脑或多设备汇总，只能手动复制数据目录。
- 新增联网功能必须写进 [PRIVACY.md](../../PRIVACY.md) 并能关掉；[贡献指南](../../CONTRIBUTING.md)把上传、遥测类改动列为不接受。
