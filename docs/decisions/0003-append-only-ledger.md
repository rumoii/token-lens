# 0003 账本只增不删：未知不是零，日志消失不撤销用量

日期：2026-11-03　状态：有效

## 背景

各工具的日志会被客户端清理、改写或拆分，同一条记录可能被读到很多次，有的字段有时写有时不写。要让“这个月花了多少”可信，账本不能跟着日志的变化忽多忽少。

## 决定

- 每条记录有不含 token 数的稳定身份；重复读取只更新原行，不新增。
- 只增不删：记录从日志里消失记为 `vanished`，照常计数；被新版解析器取代的行停用但保留。
- 不知道的字段存 NULL，不当成零；查询逐列求和，不让一个 NULL 吞掉整行。
- 金额用整数微美元，按任何维度分组之和都等于总数。

完整规则见 [账本契约](../development/ledger.md)。

## 放弃的做法

- 每次同步清空重建：日志被清理后历史用量就丢了。
- 缺字段时补零：会把“未知”显示成“没用”，看起来比实际少。

## 后果

- 账本只会变大；解析规则改变时要升解析器版本，由入账逻辑停用旧行，而不是直接改数据。
- 结构升级前自动保存一份完整备份，升级后旧版程序打不开新账本。
