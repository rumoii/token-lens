# 检查更新

## 请求与联网边界

Dart 的 `UpdateController` 管理本应用的更新检查，不读取用量或统计账本。当前版本来自现有 `health` FFI 的 `version`，即 `app/rust/Cargo.toml` 中 crate 版本对应的 `CARGO_PKG_VERSION`。当前版本必须完全匹配 `X.Y.Z`，否则不检查、禁用检查按钮，更新卡按从未检查显示，版本位置为“—”。

固定请求为 `GET https://api.github.com/repos/rumoii/token-lens/releases/latest`，无查询参数。应用设置的请求头只有：

| 请求头 | 值 |
| --- | --- |
| `Accept` | `application/vnd.github+json` |
| `X-GitHub-Api-Version` | `2022-11-28` |
| `User-Agent` | `TokenLens-Update` |

请求不携带账号、Cookie、认证、凭据、用量、当前版本号或其他本机信息。HTTP 协议自身所需的目标主机头由客户端处理。请求不跟随重定向，3xx 为失败。连接与读取共用 15 秒期限；超过 512 KiB 的声明长度或流式正文立即中止，结果为 `invalid`。请求结束关闭连接；控制器释放取消定时器、关闭进行中的连接并丢弃迟到结果。不自动下载或安装。

## 解析与状态

200 响应必须是 JSON 对象，`draft` 和 `prerelease` 均严格等于 `false`，`tag_name` 完全匹配 `^v(\d+)\.(\d+)\.(\d+)$`。不接受预发布后缀、构建元数据或前后空白。版本按三段整数比较。`published_at` 能解析为时间时保留，缺失或无法解析时留空。下载地址不取响应的 `html_url`，而是由已校验版本拼接 `https://github.com/rumoii/token-lens/releases/tag/v<版本>`；点击后交给现有 `openLink` 在系统浏览器打开。

| 条件 | kind | 更新卡状态 |
| --- | --- | --- |
| 200，最新版本大于当前版本 | `available` | “{最新} 可以更新了”，打开下载页、检查更新和忽略当前提示的链接 |
| 200，最新版本小于或等于当前版本 | `latest` | “{当前} 已是最新”，显示检查时间 |
| 404 | `none` | “{当前} 是目前唯一的版本”，说明 GitHub 尚无正式发布 |
| 403、429 | `limited` | “没检查成功”，说明 GitHub 暂时拒绝请求，允许重试 |
| 200 内容不合法或正文超限 | `invalid` | “没检查成功”，说明返回内容读不懂，允许重试 |
| 其他状态、3xx、网络错误或超时 | `offline` | “没检查成功”，说明连不上 GitHub，允许重试 |

检查中显示“正在检查…”，检查按钮禁用。从未检查时显示当前版本及自动检查开关状态。失败后的下一次自动尝试仍受 24 小时间隔限制；手动重试不受限制。时间采用本地日期：今天、昨天或月日，跨年加年份；检查时间带时分，发布日期只显示日期。

## 调度与生命周期

自动检查默认开启。启动约 10 秒后判断一次，此后每小时判断一次。首次引导完成、开关开启且从未尝试过或距上次尝试满 24 小时时发起检查；上次尝试时间在未来也视为已满。关闭后重新打开开关立即按同样条件判断。手动“检查更新”和“重试”忽略开关及 24 小时间隔。

同一时间只允许一个请求，检查中再次触发直接忽略。检查开始时保存尝试时间，成功失败均计入间隔。状态为 idle → checking → result；关闭控制器后不再创建请求，未完成结果不再持久化或通知界面。时钟、定时器与请求函数可注入，测试使用假请求与假时间，不向 GitHub 联网。

## 持久化与提示

字段保存在现有 `ui-preferences.json` 中，由 `UiPreferences` 读写，沿用偏好文件的串行原子写入。旧文件缺少字段时使用默认值；旧读者忽略新增字段，再写入时可以丢失更新状态，不影响账本。

| 字段 | 类型与默认值 |
| --- | --- |
| `autoCheckUpdates` | 布尔，默认 `true`，非法值按开启处理 |
| `updateLastAttemptMs` | 上次尝试的 epoch 毫秒，正整数或空 |
| `updateKind` | 六种结果的枚举名或空；不保存 checking |
| `updateLatestVersion` | `available` 的最新 `X.Y.Z` 或空 |
| `updatePublishedAtMs` | `available` 的发布时间，正整数 epoch 毫秒或空 |
| `updateIgnoredVersion` | 用户忽略的 `X.Y.Z` 或空 |

非法版本字段被丢弃；非法尝试与发布时间被丢弃。`available` 缺少有效版本时丢弃整个结果。没有有效尝试时间的非 available 结果按从未检查显示。升级后，已保存版本不高于当前版本时更新卡显示已是最新。

侧栏分隔线下、同步状态上显示“有新版本 {最新}”，所有页面与窄屏抽屉共用同一状态。只在上次结果为 `available`、最新版本大于当前版本、且不同于忽略版本时显示。点击提示跳到设置页并滚动到更新卡；点击 × 或卡内“这个版本不再提示”只记住该版本，卡片继续显示更新。更高版本再次提示，升级后提示自动消失。提示行与 × 均支持 Tab、回车和 `LensFocusOutline` 焦点样式。

## 发布版本

`app/pubspec.yaml` 的 `version` 去掉 `+` 后部分，必须与 `app/rust/Cargo.toml` 的 `[package].version` 一致。Flutter 测试读取两处值核对；发布工作流在构建前读取两处值，并同时核对 Git 标签，任一不一致均失败，错误包含具体版本。
