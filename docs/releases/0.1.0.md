# Token Lens 0.1.0

首个公开版本。Token Lens 读取 28 款 AI 编程工具写在本机的日志，统计每个工具、模型、项目、会话用了多少 token、按公开价约值多少钱，以及每次请求等了多久、回复得多快。不登录、不上传、没有遥测。

## 包含什么

- 用量总览、明细、会话、请求计时、工具、价格与设置六个页面，以及首次引导。
- 28 款工具的日志解析；证据等级（实测、有样本待对照、实验性）见 [README 的支持列表](../../README.md#支持的工具)。
- 随包附带的只读 JSON 命令行 `token-lens-cli`，明细导出 CSV 或 JSON。
- AI 热点：20 个新闻和更新来源，可以在首次引导或设置里关掉。
- 中文和英文界面，深色模式，紧凑模式和界面缩放。

## 已知限制

- 程序没有代码签名，macOS 版也没有公证，第一次打开时系统会拦一下。
- macOS 版在 GitHub 的 macOS runner 上构建并跑过冒烟，还没有在真机上完整验收。
- 没有安装程序，两个平台都是解压即用的 zip。
- 标为“实验性”的工具只用合成样本验证过，可能读不到或读不全；日志放在非默认位置的工具暂时读不到。
- 金额按公开价估算，不是账单。

# Token Lens 0.1.0 (English)

The first public release. Token Lens reads the logs that 28 AI coding tools write on your machine and shows the tokens each tool, model, project and session used, the estimated cost at list prices, and how long each request waited and how fast it streamed. No sign-in, no uploads, no telemetry.

## What's included

- Overview, Breakdown, Sessions, request timing, Tools, and Pricing & settings, plus first-run setup.
- Log parsing for 28 tools; evidence levels (verified, real samples pending, experimental) are listed in the [README](../../README.en.md#supported-tools).
- The bundled read-only JSON CLI `token-lens-cli`, and CSV or JSON export of the breakdown.
- AI news from 20 news and changelog sources, which can be turned off during setup or in Settings.
- English and Chinese interface, dark mode, compact mode and interface scaling.

## Known limitations

- The app is not code-signed and the macOS build is not notarized, so the system stops it on first launch.
- The macOS build is built and smoke-tested on GitHub's macOS runners but has not been fully tested on real hardware.
- There is no installer; both platforms ship as zip files.
- Tools marked experimental are verified only against synthetic samples and may be missed or read incompletely; logs stored in non-default locations are not read yet.
- Costs are estimates at list prices, not your bill.
