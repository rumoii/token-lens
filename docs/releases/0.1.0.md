# Token Lens 0.1.0

首个公开版本。Token Lens 读取你电脑上 28 款 AI 编程工具的日志，告诉你每个工具、模型、项目、会话用了多少 token、按公开价约值多少钱，以及每次请求等了多久、回复得多快。不用登录，不上传，没有遥测。

## 用量：今天用了多少，花在哪了

打开就是用量总览：今天、本周、本月或任意时段用了多少 token、约值多少，比上一期多了还是少了；点开对比能看到是哪些项目、工具或模型多了、少了。趋势图按小时或按天，可以切换看 token 或金额，下面还有一年的活跃热力图。

- 明细按时间、工具、模型、项目拆开看，筛选可以叠加，每一行都分开显示新输入、输出、读缓存、写缓存四类 token。
- 会话页看每个会话用了多少、按天怎么分布、调用了哪些模型。
- 请求计时显示首字要等多久、回复每秒出多少 token；日志里没记时间的工具会写明原因。

## 迷你窗口：边用 AI 边看用量

总览和明细页右上角的「迷你窗口」，能把主窗口切成一个可以置顶的小面板，放在屏幕一角，边写代码边看：今天的总用量、各项目用量、最近 5 分钟在用的模型和大致速度、最近 15 分钟到 1 小时的用量曲线，以及最近几次请求。

- 刷新间隔可选 5 秒到 5 分钟；显示几个项目也可以自己定。
- 鼠标指到曲线上（或用方向键）能看某一分钟用了多少。
- 第一次打开总览时会提示一次，关掉或用过之后不再出现。

## 第一次打开

首次引导会列出在这台电脑上找到了哪些工具、各有多少日志文件，点「开始统计」就开始读。

- 统计时会显示读到了第几个文件、每个工具读完没有、已经用了多久。日志多的话，第一次统计可能要几分钟；以后打开只读新增的部分，会快很多。
- 不用等它读完，可以先点「去看看」，统计在后台继续；中途关掉窗口也没关系，下次打开会接着读。
- Windows 上默认在桌面创建快捷方式；以后挪动了程序文件夹，可以在「价格与设置」里重新创建。
- 不想看 AI 热点的话，引导里勾上「只用本地统计，不刷 AI 热点」就不会联网取新闻。

## 价格

金额按各模型的公开价估算，包括长上下文分档和 DeepSeek 的高峰、低谷价，默认用人民币显示（也可以在设置里换成美元）。这只是用来比较和感知的估值，不是你的账单；用套餐的话，实际花费通常更低。

价格表随版本更新。刚发布、价格表里还没有的模型显示「未定价」，不算进金额，也不会拿同系列的价格去猜；总览上会写明有多少条记录没有价格。

## 其他

- AI 热点：20 个官方博客、更新日志和社区来源的新闻，可以在首次引导或设置里关掉。
- 随程序附带只读的 JSON 命令行 `token-lens-cli`，明细也能导出成 CSV 或 JSON，给脚本和 AI 助手用。
- 中文和英文界面，深色模式，紧凑模式和界面缩放。
- 只读取各工具日志里的用量字段，提示词、回复和代码不会写进账本，也不会发出去。会联网的只有 AI 热点、手动更新汇率和每天最多一次的检查更新，详见 [隐私说明](https://github.com/rumoii/token-lens/blob/main/PRIVACY.md)。

## 已知限制

- 程序没有代码签名，macOS 版也没有公证，第一次打开时系统会拦一下，放行方法见安装指南。
- macOS 版在 GitHub 的 macOS 机器上构建并跑过冒烟测试，还没有在真机上完整验收。
- 没有安装程序，两个平台都是解压即用的 zip。
- 标为“实验性”的工具只用合成样本验证过，可能读不到或读不全；日志放在非默认位置的工具暂时读不到。
- 少数客户端内部的模型名（例如带档位后缀的）对不上公开价，会显示「未定价」。

# Token Lens 0.1.0 (English)

The first public release. Token Lens reads the logs that 28 AI coding tools write on your computer and shows how many tokens each tool, model, project and session used, what that would cost at list prices, and how long each request waited and how fast it streamed. No sign-in, no uploads, no telemetry.

## Usage: how much you used today, and where it went

The app opens on the overview: tokens and estimated cost for today, this week, this month or any range, compared with the previous period. Open the comparison to see which projects, tools or models went up or down. Trend charts show hours or days in tokens or cost, with a year-long activity heatmap below.

- Breakdown splits usage by time, tool, model or project, with stacked filters; every row shows input, output, cache read and cache write separately.
- Sessions shows what each session used, how it spread across days and which models it called.
- Request timing shows time to first token and tokens per second; tools whose logs lack timestamps say why.

## Mini window: watch usage while you work with AI

The "Mini window" button at the top right of Overview and Breakdown turns the main window into a small panel that can stay on top in a corner of the screen: today's total, usage per project, models used in the last 5 minutes with their approximate speed, a usage chart for the last 15 minutes to 1 hour, and recent requests.

- Refresh every 5 seconds to 5 minutes, and choose how many projects to show.
- Point at the chart (or use the arrow keys) to see a single minute.
- The overview suggests it once; after you close the tip or open the mini window, it stays away.

## First run

Setup lists the tools found on this computer and how many log files each has. Click "Start counting" to begin.

- While counting, it shows how many files have been read, which tools are done, and how long it has taken. With lots of logs, the first count may take a few minutes; after that, only new entries are read, so it's much faster.
- No need to wait: click "View usage" and counting continues in the background. If you close the window, it picks up where it left off next time.
- On Windows it creates a desktop shortcut by default; if you move the app folder later, create it again in Pricing & settings.
- To skip AI news, tick "Local statistics only, no AI news" during setup and no news is fetched.

## Pricing

Costs are estimated from each model's list price, including long-context tiers and DeepSeek's peak and off-peak rates, and are shown in CNY by default (switch to USD in Settings). They are for comparison only and are not your bill; on a subscription plan you usually pay less.

Prices ship with each release. Models too new for the price table show as "Unpriced", are left out of the cost, and are never priced by guessing from a similar model; the overview says how many records have no price.

## Also included

- AI news from 20 official blogs, changelogs and community sources, which you can turn off during setup or in Settings.
- The bundled read-only JSON CLI `token-lens-cli`, plus CSV or JSON export of the breakdown, for scripts and AI agents.
- English and Chinese interface, dark mode, compact mode and interface scaling.
- Only usage fields are read from the logs; prompts, replies and code never enter the ledger or leave your computer. The only network use is AI news, updating the exchange rate when you ask, and checking for updates at most once a day. See the [privacy notes](https://github.com/rumoii/token-lens/blob/main/PRIVACY.md).

## Known limitations

- The app is not code-signed and the macOS build is not notarized, so the system stops it on first launch; the installation guide shows how to allow it.
- The macOS build is built and smoke-tested on GitHub's macOS runners but has not been fully tested on real hardware.
- There is no installer; both platforms ship as zip files.
- Tools marked experimental are verified only against synthetic samples and may be missed or read incompletely; logs stored in non-default locations are not read yet.
- A few client-internal model names, such as ones with tier suffixes, do not match a public price and show as "Unpriced".
