# Token Lens 功能规格

本文件只描述 Token Lens 自身要做的事、优先级和验收条件。它不引用任何外部项目，也不把外部文档的声明当作本项目的能力证明。

事实来源只有两类：本机真实落盘的日志（见 [log-schemas.yaml](log-schemas.yaml)）和本项目自己跑出来的验证输出。

---

## 一、定位与边界

纯本地、无账户、无上传的 AI 编码工具用量与成本统计。

- 只读客户端已经写在磁盘上的日志与数据库，不向任何客户端安装 Hook、插件或修改其配置。
- 不保存提示词、回复、代码、附件、凭据。
- 联网只发生在用户明确点击时（价格刷新、额度查询、服务状态）。
- 单机单用户，服务只监听回环地址。

## 三、验收条件

### G1 采集

1. 同一记录被重复读到，不新增行、不改变总额。
2. 同一稳定身份的用量增长，更新原行（`revision` 递增），旧值不残留成第二行。
3. 累计型来源的会话累计值增长，只覆盖，不累加。
4. 累计值下降时报告异常，不静默保留两套数。
5. 坏记录、缺字段、零用量三类分别计数并单独报告，不混成一个数字。
6. 缓存读写与输入输出不重叠：`gross = input + output + cache_read + cache_write`。
7. 不持久化除 token 数、时间、模型名、会话标识以外的内容。

### G2 统计

1. Summary、日、月、时、模型、来源、会话七个视图对同一数据集，Token 与金额差额均为 0。
2. 分项加和等于顶部总额，金额按最大余数法分配尾差。
3. 缺失数据是未知，不补 0。
4. 无法确定逐日分布的累计用量进「时间未分配」桶，不伪造每日曲线。
5. 一次页面刷新使用同一数据快照、同一筛选条件、同一时区、同一价格版本。

### G3 会话

1. 分页稳定：同一查询在数据不变时返回相同分页边界。
2. 会话详情只展示聚合数值，不展示对话内容。

### G5 估值

1. 每条价格带官方来源链接、币种、核验日期。
2. 未知模型显示「未定价」，不显示 0 或免费。
3. 换价格版本只重算金额，不改用量事实。
4. 界面明示金额是估算市场价值，并显示价格版本日期。

### G6 同步

1. 同步任务串行，跨进程互斥。
2. 中断后不留下半写的统计状态。
3. 失败原因可见，不吞掉。

### G7 本地运行

1. 空用户目录下首条命令即可用，不需要预先建目录。
2. 数据目录由统一解析器决定，冲突时报出原因。
3. 模块导入不产生副作用（不开库、不扫盘、不建目录）。

### G14–G16 外部查询

1. 页面加载、后台同步、定时任务都不触发外部请求。
2. 触发必须来自用户点击，且失败原因可见。

## 四、默认排除

以下不实现，也不作为未完成项：

| 排除项 | 理由 |
|---|---|
| 云账户、上传、跨设备合并 | 与「纯本地」冲突 |
| 公开排行榜、分享页 | 需要云端与身份 |
| 遥测、心跳、行为分析 | 未经用户同意的上行流量 |
| 桌面小组件 | 维护面与收益不成比例 |
| 宠物、成就 | 与用量统计目标无关 |
| Skills 管理 | 会写其他工具的配置 |
| 徽章生成 | 需要云端函数 |
| 自动安装 Hook | 会改用户其他工具的配置 |

## 五、验收失败的判定

任何一条视图自相矛盾、任何一条采集重复计数、任何一处把未知显示为 0 或免费，都算未完成，不因为「其他功能正常」而放行。
